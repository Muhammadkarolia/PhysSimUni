About This Project

This application is a 2D N-body gravitational simulation that models the interaction between N amount of bodies using Newton's Law of Universal Gravitation. Users can create bodies interactively by dragging on the canvas or through precise input, and observe emergent behaviour in real time.

Features

Creation Modes: The system supports both interactive and precise methods for defining initial conditions, allowing bodies to be created through direct manipulation or exact parameter specification.

Mass Control: Mass values can be dynamically configured, enabling exploration of how variations in mass influence gravitational interactions and system behaviour.

Simulation Control: The simulation provides real-time control over execution, including the ability to start, pause, reset, and monitor the current state of the system.

N-Body Simulation: Implements a real-time N-body system in which all bodies interact through gravitational forces, producing complex and emergent motion.

Object Creation: Supports flexible object creation through both intuitive interaction and precise numerical input, enabling a wide range of experimental setups.

Vector Visualisation: Displays velocity and net force vectors, providing insight into the dynamics and interactions between bodies.

Collision Handling: Detects and resolves collisions between bodies through merging behaviour, conserving momentum within the system.

Orbital Trails: Renders motion trails for each body, allowing paths and orbital patterns to be visualised over time.

Adjustable Parameters: Key simulation parameters can be modified, allowing experimentation with different conditions and observation of their effects.

Design Decisions

Several design choices were made to balance accuracy, performance, and usability. Euler integration was selected for its simplicity and computational efficiency, making it suitable for real-time visualisation despite minor accuracy limitations. Scaled, non-real-world units are used to ensure stable and visually meaningful behaviour within the constraints of a browser-based environment. A softening constant is included to avoid singularities in force calculations, and a dual input system was implemented to support both intuitive interaction and precise configuration of initial conditions.

How It Works

The simulation models gravitational interactions between multiple bodies using Newton's Law of Universal Gravitation, which states that every point mass attracts every other point mass with a force proportional to the product of their masses and inversely proportional to the square of the distance between them. Gravitational forces are calculated between all pairs of bodies and resolved into horizontal and vertical components. These forces are then used to update each body's velocity and position over time using Euler integration. A softening factor is applied to maintain numerical stability and prevent extreme forces at very small distances, allowing the system to produce smooth and continuous motion in real time.
